Personal Project
SmartAccommodationFinder — Student Room Rental Platform (Microservices)
05/2026  –  Present
Role: Full-stack Developer
Description: A polyglot microservices platform connecting students with landlords for room searching, scheduling viewings, and online deposit payment. Features include real-time notifications via WebSocket, in-app chat, and interactive map integration across 7 independent microservices.
Tech Stack: Java, TypeScript, JavaScript (ES6+), Spring Boot 3.3, Node.js, React 19, React Native, MariaDB, MongoDB, RabbitMQ, Docker Compose, Nginx, JWT, Socket.IO
Key Features:
  • Designed a Polyglot Microservices architecture with 7 independent services (Auth, Room, Booking, Payment, Notification, Messaging) following the Database-per-Service pattern with 5 MariaDB instances and 1 MongoDB for chat messages.
  • Implemented RabbitMQ Topic Exchange fan-out pattern with separate queues (saf.notification.queue, saf.socket.queue) ensuring independent full delivery to all consumers, eliminating competing consumer message loss.
  • Built real-time notification and chat system using Socket.IO with users joining dedicated rooms (user_{id}) for targeted push delivery; combined with 30-second polling fallback for offline catch-up.
  • Integrated OpenFeign for declarative inter-service HTTP calls (Booking → Room/Auth, Payment → Booking/Room) with Resilience4j Circuit Breaker automatically returning fallback responses when dependent services fail.
  • Implemented JWT stateless authentication (accessToken 15 min + refreshToken 7 days) with Axios interceptors auto-refreshing expired tokens on 401 responses without user interruption.
  • Containerized the entire system with Docker Compose orchestrating 12 containers; Nginx serves as the single API Gateway on port 80, routing all traffic internally and serving the React SPA as static files.
