SmartAccommodationFinder — Nền tảng tìm kiếm & đặt phòng trọ thông minh (Microservices)
05/2026  –  Nay
Vai trò: Lập trình viên Fullstack
Mô tả: Nền tảng microservices đa ngôn ngữ kết nối sinh viên với chủ trọ, hỗ trợ tìm kiếm phòng theo bộ lọc đa tiêu chí, đặt lịch xem phòng, thanh toán đặt cọc trực tuyến, chat real-time và thông báo tức thì qua WebSocket trên 7 microservice độc lập.
Công nghệ: Java, TypeScript, JavaScript (ES6+), Spring Boot 3.3, Node.js, React 19, React Native, MariaDB, MongoDB, RabbitMQ, Docker Compose, Nginx, JWT, Socket.IO
Tính năng nổi bật:
  • Thiết kế kiến trúc Polyglot Microservices gồm 7 service độc lập (Auth, Room, Booking, Payment, Notification, Messaging, AI Chat) theo mẫu Database-per-Service với 5 MariaDB và 1 MongoDB riêng biệt cho từng service.
  • Triển khai mẫu RabbitMQ Topic Exchange fan-out với 2 queue độc lập (saf.notification.queue, saf.socket.queue), đảm bảo mỗi consumer nhận đủ 100% message mà không bị mất do cạnh tranh (competing consumers).
  • Xây dựng hệ thống thông báo và chat real-time bằng Socket.IO — user join room riêng theo userId (user_{id}) để nhận push đúng đích; kết hợp polling 30 giây làm fallback khi offline.
  • Tích hợp OpenFeign cho các lời gọi HTTP giữa services (Booking → Room/Auth, Payment → Booking/Room) kết hợp Resilience4j Circuit Breaker tự động trả về fallback khi service phụ thuộc bị lỗi.
  • Xác thực người dùng bằng JWT không trạng thái (accessToken 15 phút + refreshToken 7 ngày) kết hợp Axios interceptors tự động làm mới token khi nhận lỗi 401 mà không cần người dùng đăng nhập lại.
  • Đóng gói toàn bộ hệ thống bằng Docker Compose điều phối 12 containers; Nginx đóng vai trò API Gateway duy nhất tại cổng 80, định tuyến traffic nội bộ và phục vụ React SPA dưới dạng file tĩnh.
